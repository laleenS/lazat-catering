# Lazat Catering

A catering website demo made with HTML, CSS, and JavaScript, based around
Indo-Pakistani food. It has a sample menu, a food gallery, and an enquiry preview.
The colours are cream, red, and black.

The main things this project focuses on are responsive layouts, a mobile menu,
and basic form handling. The menu supports keyboard navigation, and the form shows
a preview using the details entered. It does not send email or accept bookings.

## View locally

Open a terminal in the project folder and run:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`. There are no packages to install or build steps.
If Node.js is installed, `node --check script.js` checks the JavaScript syntax.

This is a student demo. Prices and the service area are examples. The food photos
use Unsplash URLs and are not photos of dishes prepared by this business. Google
Fonts and the photos need an internet connection, but the page has fallbacks.
Use fictional details when trying the form.

Before using this for a real business, the contact details, prices, photos, and
business information would need to be confirmed, and enquiries would need a working
backend.
